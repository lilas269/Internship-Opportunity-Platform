# Internship Opportunity Platform

## Project Overview
The Internship Opportunity Platform is a web-based system designed to connect university students with companies offering internship opportunities.

The platform aims to simplify the process of publishing internship opportunities, submitting applications, and tracking application statuses.

## Main Users
- **Students:** Browse internship opportunities and submit applications.
- **Company Representatives:** Publish internship opportunities.
- **Training Office Administrators:** Review opportunities and manage student applications.

## Main Features
- Browse available internship opportunities.
- View internship opportunity details.
- Submit internship applications.
- Track application statuses.
- Review and manage internship opportunities.
